# Google Lens Bridge

这是一个可选的 Chrome 扩展桥接器。它优先在当前 Chrome 会话中向 Google Lens 的真实上传接口提交帧，并等待结果页；如果浏览器拒绝表单提交，才退回文件选择框，必要时自动保存临时文件。用户不需要手动打开或替换文件。搜索页在后台标签中运行，解析完成后自动关闭，结果链接和命中数量会回传到本地页面。开始新的搜索时，扩展会关闭上一轮自动打开的 Google 标签页。

安装：打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，选中本目录。然后刷新 `http://127.0.0.1:4173/`。如果直接打开 `dist/index.html`，请在扩展详情中开启“允许访问文件网址”。

扩展需要 `debugger`、`downloads` 和 Google 页面权限。帧图只会发往 Google Lens；扩展会在 Google 结果页读取普通外链、Google `/goto` 包装链接和视觉匹配卡片，并把去重后的候选链接、标题和命中数量回传给本地页面显示。
